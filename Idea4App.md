## Pre-requisites
- **Node.js**: Version 18.0.0 or higher is required (v20+ recommended).
- **npm** / **pnpm** / **yarn**: Package manager of your choice.

## Installation
To install the dependencies:
```bash
npm install
```
*(or run `pnpm install` or `yarn install` if preferred)*

## Running the Application
### Development Server
To run the app locally in development mode:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) in your browser.

### Build & Deploy
To compile the project for production deployment:
```bash
npm run build
```

To start the production server locally after building:
```bash
npm run start
```
